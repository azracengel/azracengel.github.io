# How this site is built

- This is a static personal website using HTML, CSS, and a little plain JavaScript. Do not add frameworks, npm, a server, or a database.
- Follow the requirements and content decisions in PRD.md. Ask before adding pages or sections that are not included there.
- Keep the design clean, modern, professional, and responsive on both desktop and mobile.
- Keep all styling in style.css and keep the HTML and CSS simple and readable.
- Use lowercase file and folder names with hyphens and no spaces.
